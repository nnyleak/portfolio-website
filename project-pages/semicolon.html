semicolon;

about this project.

semicolon; is a simple, minimalistic blog app built using Node.js, Express, and EJS, styled using Bootstrap and custom CSS. It features a cozy, diary-inspired interface where users can create and edit blog posts through a simple CRUD system.

Journaling has always been one of my quiet comforts, which strongly influenced the look and feel of this project. I like building projects that reflect who I am, and journaling has always helped me organize my thoughts without feeling pressured to act upon them immediately. It's a way of pausing life for a moment; to process, breathe, then continue. Much like how a semicolon breaks up a sentence without ending it. I wanted this site to capture that feeling.
